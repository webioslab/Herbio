# Neuroscience meets AI — Summer School website

A responsive static website for **Brain Summer School 2026: Neuroscience meets AI**, associated with Research Project 1 of HERBioLab.

## Included
- Overview and event details
- Six activity cards
- Five-day high-level learning journey
- Partner section
- Starter learning resources
- Mobile navigation and responsive layout

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `neuroscience-meets-ai`.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.

## Before publishing
- Confirm the official programme and replace the illustrative day-by-day outline if needed.
- Add approved partner logos and required acknowledgements.
- Add real photos, workshop materials, project outputs, and contact details.
- If the site is being used after the event, consider adding a gallery, participant projects, and downloadable materials.

## Edit the content
Most text is in `index.html`. Colors, typography, layout, and mobile styling are in `styles.css`. Mobile menu behavior is in `script.js`.

This site uses no build tools or frameworks; it can be hosted directly by GitHub Pages.
